# Digital User Directory

## Overview
A React-based user directory application that fetches user data from a public API and provides navigation between a list view and a detailed profile view.

## Features
- View list of users
- Navigate to individual user profiles
- Client-side routing using React Router
- API integration using useEffect

## Tech Stack
- React
- React Router DOM
- JSONPlaceholder API

## Folder Structure
src/
  components/
    UserCard.jsx
  pages/
    Home.jsx
    UserProfile.jsx
  App.jsx
  main.jsx

## Installation

```bash
npm install
npm install react-router-dom
npm run dev
```

## API Used

```bash
https://jsonplaceholder.typicode.com/users
```
